# Slash commands

Type `/` in the chat box for the menu. Arrow keys move, Tab or Enter picks, Esc closes. Hover an entry to see what it does. It lists:

| Entry | What it does |
| --- | --- |
| `/compact` | Summarize the conversation so far to free context; shows a live timer, then "Compacted N tokens" ([details](context.md)) |
| `/compose` | Turn Compose mode on or off |
| `/new` | Start a new chat |
| `/<skill-name>` | Load that skill for this message |
| MCP servers | Insert "Use the *server* MCP server to …" |
